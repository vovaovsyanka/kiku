# Кику — локальная голосовая помощница-горничная для ПК

Полностью локальный голосовой ассистент для Windows: слышит вас, понимает русский, управляет папками,
файлами и приложениями, помнит задачи и факты о вас, отвечает голосом.
Никаких облачных API, никаких внешних серверов моделей: всё работает внутри одного Python-процесса,
модели скачиваются с Hugging Face один раз и дальше лежат в `./models`.

> Логика ядра покрыта тестами без моделей (`python -m unittest discover -s tests -v`).
> Что может пойти не так на вашем железе — см. раздел «Известные риски».

## Что умеет сейчас

«Быстрые» команды выполняются шаблонами за доли секунды, без языковой модели. Всё остальное понимает LLM.

| Область | Примеры фраз | Как работает |
|---|---|---|
| Папки | «открой загрузки», «открой документы/учёба», «что лежит на рабочем столе?» | быстро / LLM |
| Файлы | «создай файл заметки.txt на рабочем столе с текстом привет», «создай папку Проекты» | LLM |
| Приложения | «запусти кс», «открой блокнот» (только белый список `apps`) | быстро |
| Окна | «сверни вс код», «разверни хром», «переключись на телеграм», «сверни все окна», «какие окна открыты?», «закрой телеграм» (с подтверждением) | быстро / LLM |
| Звук и медиа | «громче», «тише», «без звука», «пауза», «следующий трек» | быстро |
| Система | «который час», «заблокируй компьютер» (с подтверждением) | быстро / LLM |
| Задачи | «добавь задачу сдать курсовую до двадцатого октября», «какие у меня задачи», «отметь первую выполненной» | быстро (список) / LLM |
| Память | «запомни, что я пью зелёный чай», «что я говорил про чай?», «забудь это» (с подтверждением) | LLM |
| Поиск файлов | «проиндексируй мои папки», «где лежит конспект по линейной алгебре?», «открой его» | LLM |
| Чтение файлов | «прочитай мою заметку на рабочем столе» (только текстовые файлы: txt, md, csv, json, py…, первые 4000 символов) | LLM |

### «Изюминки»: что Кику делает сама и за вас

| Умение | Примеры фраз | Как работает |
|---|---|---|
| **Напоминания и таймеры** | «напомни через 20 минут выключить чайник», «напомни завтра в девять утра позвонить маме», «поставь таймер на пять минут», «какие у меня напоминания», «отмени все напоминания» | быстро; Кику **сама заговорит** в нужный момент. Хранятся в базе: не пропадут при перезапуске, а если срок прошёл, пока она была выключена, она об этом скажет |
| **Режимы (сцены)** | «я играть» (сворачивает окна, запускает CS2, добавляет громкость), «рабочий режим», «спокойной ночи» (пауза, сворачивание, блокировка) | быстро; цепочки действий описаны в `config.yaml → scenes`, свои добавляются без кода |
| **Сводка и инициатива** | «доброе утро» / «сводка» — дата, задачи (на сегодня и просроченные), напоминания, погода | первый запуск за день — сводка сама; каждые 90 минут непрерывной работы — предложение размяться (`proactive`) |
| **Врач для ПК** | «что тормозит», «сколько свободно памяти», «сколько места на диске», «сколько заряда», «закрой хром» (с подтверждением) | быстро (`psutil`); системные программы закрыть нельзя |
| **Буфер обмена и диктовка** | «переведи то, что я скопировал», «перескажи скопированное» (результат кладётся в буфер, вставьте Ctrl+V), «набери текст: Здравствуйте, Анна!» | LLM / быстро; диктовка вставляет текст через Ctrl+V и возвращает прежний буфер |
| **Порядок в папках** | «разбери загрузки», «наведи порядок на рабочем столе», «найди дубликаты», «убери дубликаты», «верни как было» | после вашего «да»; ничего не удаляется, всё можно отменить |
| **Дневник** | «запиши в дневник: сегодня сдал курсовую», «что я записывал за неделю» | быстро / LLM |
| **Поиск по тексту файлов** | «проиндексируй тексты в документах», «где я писал про договор с хостингом» | LLM; хранится текст txt/md/csv… из разрешённых папок |
| **Погода и курсы** | «какая погода в Москве», «курс доллара» | **выключено по умолчанию** (`internet.enabled`), других обращений в сеть нет |
| **Болтовня** | «привет», «спасибо», «как дела» | мгновенно, без LLM |

Кнопка **«?»** в окне показывает этот список самой Кику.

**Пока не умеет** (нет инструментов, это не «ограничение системы»): нажимать кнопки в чужих программах, видеть экран,
читать PDF/Word и бинарные файлы, искать в интернете (кроме погоды и курсов), управлять яркостью, Wi-Fi и питанием,
отвечать на вопросы о событиях после даты обучения модели. Если просьба вне списка, Кику должна прямо сказать, что этого не умеет.

Индекс поиска хранит только **имена** файлов и папок. Содержимое она читает лишь по прямой просьбе и только текстовые файлы;
после чтения файла Кику может только отвечать, а не менять систему (защита от «приказов» внутри файла, см. «Безопасность»).

## Окно с Кику и Kiku.exe

`python -m kiku gui` открывает окно **на весь экран** (`gui.start_maximized`; F11 — полноэкранный режим, Esc — выйти из него):
по центру Кику, сверху текст её ответа, снизу распознанная вами фраза, внизу строка для команд текстом.
Текст ответа появляется в тот момент, когда Кику начинает его произносить. Кнопка **«?»** в правом верхнем углу (или F1)
открывает справку «Что умеет Кику» (текст справки — `kiku/ui/skills.py`).

| Что происходит | Поза Кику |
|---|---|
| ждёт | стоит и улыбается (слегка «дышит») |
| слышит речь (любую, пока вы говорите и пока идёт распознавание) | рука у уха |
| выполняет команду, ждёт ответ модели и озвучку | задумалась |
| звучит её голос | говорит (покачивается в такт) |

Фразы без имени «Кику» тоже показываются внизу серым с пометкой «(не мне)», но Кику на них не отвечает (если не идёт
окно диалога). Модели грузятся в фоне, окно появляется сразу. Если голос или микрофон не загрузились, окно работает
как текстовый чат. Лог пишется в `data/kiku.log` (в окне консоли нет).

**Kiku.exe — без консоли.** Выполните один раз `python scripts/build_exe.py` (подойдёт любая оболочка, в том числе Git Bash):
он соберёт маленький `Kiku.exe` и положит его в корень проекта. Двойной щелчок по нему запускает окно; ярлык на рабочий стол: ПКМ — Отправить — Рабочий стол.
Это лаунчер, а не «всё в одном exe»: он находит в проекте виртуальное окружение (`kikuenv`, `.venv`, `venv`) и запускает
там `pythonw -m kiku gui`. Поэтому папка проекта, окружение и `models` должны оставаться на месте, а exe нельзя просто
копировать на другой компьютер. Нестандартное окружение — впишите путь к `pythonw.exe` в `launcher.txt`.
Без сборки можно так же запускать `launcher.pyw` двойным щелчком. Полноценный автономный exe со всеми моделями —
отдельная задача (многие гигабайты, хрупкая упаковка CUDA); пока не делали.

Свои картинки: положите лист 2x2 (с прозрачным фоном) в `kiku/ui/assets/source_sheet.png` и выполните
`pip install scipy` и `python scripts/make_assets.py`.

## Что на каком устройстве работает (GPU/CPU)

При запуске `python -m kiku voice` печатается отчёт «Устройства», в окне внизу появляется строка вида
`распознавание: cuda · озвучка: cuda:0 · LLM: CPU`, подробности — в `data/kiku.log`. Проверить фактическую загрузку видеокарты:
`python scripts/verify_gpu.py` (каждая проверка в отдельном процессе; показывает устройство параметров модели и загрузку GPU по nvidia-smi).

| Компонент | Где работает | Почему |
|---|---|---|
| Распознавание (Whisper, int8_float16) | GPU | ~1 ГБ видеопамяти |
| Озвучка (Silero v5, по умолчанию) | CPU | RTF ≈ 0.04, видеокарта не нужна |
| Озвучка (Qwen3-TTS 0.6B, `tts.engine: qwen`) | GPU | ~2 ГБ видеопамяти, но RTF ≈ 2.5 |
| Языковая модель (Qwen3-30B-A3B, 18.6 ГБ) | GPU + ОЗУ | модель целиком не помещается, поэтому внимание и KV-кэш (~1.6 ГБ) на видеокарте, «эксперты» MoE в оперативной памяти (`llm.n_cpu_moe`) |

Все три модели на GPU одновременно на 4 ГБ не поместятся: одна только LLM занимает в разы больше всей видеопамяти. Текущее
распределение разумно: на GPU то, что реально помещается. Генерация LLM на CPU по замеру — 13 токенов в секунду.

**Важно про Windows:** torch (и его cuDNN) должен инициализироваться раньше Whisper — это делает `kiku/cuda_init.py`.
Иначе возможен вылет `Could not load symbol cudnnGetLibConfig. Error code 127`. Если вылет остался — `asr.device: cpu` в config.yaml,
и пришлите `pip list` (строки с nvidia/ctranslate2/torch).

## Скорость: замеры и решения

Замеры на вашей машине (RTX 3050 Laptop 4 ГБ):

| Этап | Измерено |
|---|---|
| Распознавание (Whisper на GPU) | 1–4 с |
| LLM на CPU | генерация 13 ток/с (`bench_llm.py`); разбор ~900 токенов промпта 11.5 с при холодном кэше, 0.1 с при тёплом |
| Озвучка Silero v5 на CPU | RTF ≈ 0.035: 9 секунд речи синтезируются за 0.3 с |
| Озвучка Qwen3-TTS 0.6B bfloat16 (GPU) | RTF 2.4–2.6: ответ в 4 секунды звучал через ~10 с |
| Озвучка Qwen3-TTS в float16 | падает: CUDA assert (NaN при сэмплировании). Использовать только bfloat16 |

Что сделано: (1) озвучка по умолчанию — **Silero v5** (быстрый русский синтезатор): ответ начинает звучать почти сразу;
Qwen3-TTS остаётся как `tts.engine: qwen` для клонирования своего голоса; (2) озвучивается ВЕСЬ ответ, текст режется по
предложениям и играет без разрывов (`voice/speech.py`; медленному движку конвейер сам выбирает момент старта);
(3) история диалога хранится ровно в том виде, в каком её видела модель, поэтому llama.cpp переиспользует кэш;
(4) при старте LLM прогревается; (5) готовые фразы кэшируются на диск, типовые готовятся заранее; (6) типовые команды идут мимо LLM.

Остальное время уходит на LLM на CPU (несколько секунд на ответ). Ускорить её можно моделью поменьше (`llm.repo_id`, см. config.yaml).

### Голоса озвучки

Silero v5 даёт готовые голоса: женские `xenia`, `baya`, `kseniya`, мужские `aidar`, `eugene`. Чтобы выбрать «милый и живой»:

```powershell
python scripts/bench_tts.py --samples     # замер скорости + файлы data/tts_samples/silero_<голос>.wav
python scripts/bench_tts.py --pitch high --rate fast --samples   # проверить тон и темп
```

Понравившийся голос — в `config.yaml → tts.silero.speaker`, тон и темп — `tts.silero.pitch` / `rate`.
Латинские названия Silero не читает: как их произносить, задаёт `tts.pronounce`. Цифры, время и даты озвучиваются словами автоматически.
Лицензия моделей Silero — CC BY-NC (личное использование). Другие кандидаты, если Silero не устроит:
Piper (ONNX, быстрый, голоса проще), F5-TTS Russian и XTTS-v2 (живее и с клонированием, но тяжелее; на 4 ГБ видеопамяти впритык).

## Архитектура

```
Микрофон ─► Silero VAD ─► faster-whisper (ASR) ─► поиск имени «Кику» ─┐
                                                                       ▼
                                  ┌───────────── Агент (цикл) ◄── память: SQLite+FTS5
   Silero TTS ◄─ фразы ◄──────────┤   LLM (GGUF, llama-cpp-python)        факты → системный промпт
   (динамик)                      │   ответ = JSON {tool, args, say}
                                  ▼
                        Реестр инструментов ──► политика путей, белый список приложений,
                        (open_folder, create_file,   подтверждения, журнал audit.jsonl
                         launch_app, tasks, ...)
```

Ключевые решения:

* **Быстрый путь (router).** Типовые команды выполняются без LLM: это мгновенно и предсказуемо.
  Не распознанное уходит к модели.
* **Один вызов модели на команду.** Модель возвращает список действий (до четырёх) и фразу; второй вызов нужен
  только если действию нужен результат (поиск, список) или оно закончилось ошибкой.
* **Один агент + инструменты, а не «стая агентов».** Небольшие локальные модели плохо держат длинные цепочки,
  поэтому «мультиагентность» вводим точечно позже (суб-агент кода, суб-агент экрана).
* **JSON-ответ с принудительной грамматикой.** Модель обязана вернуть `{"actions":[{"tool":..., "args":...}], "say":...}`,
  а имя инструмента ограничено списком (`enum`). Это надёжнее, чем встроенный tool-calling шаблонов малых моделей.
* **Фраза `say` озвучивается сразу** (пока выполняются действия); текст на экране появляется, когда она начала звучать.
  Готовые фразы кэшируются на диск.
* **Полудуплекс:** пока Кику говорит, микрофон закрыт. Перебивать её голосом пока нельзя.
* Имя «Кику» ищется в тексте распознавания (нечётко). После ответа ещё `wake.conversation_window_sec` секунд
  (по умолчанию 25) можно говорить без имени; 0 — имя нужно в каждой команде.

## Установка (Windows 10/11, PowerShell)

Нужны: Python **3.12**, Git, свежий драйвер NVIDIA. Диск: ~30 ГБ под модели. ОЗУ: ~22–25 ГБ в работе.

```powershell
git clone <ваш-репозиторий> kiku; cd kiku
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 1. PyTorch под вашу CUDA (команду подберите на pytorch.org; пример для CUDA 12.4):
pip install torch --index-url https://download.pytorch.org/whl/cu124

# 2. Ядро (текстовый режим)
pip install -r requirements.txt
```

Если `llama-cpp-python` не собирается (нет компилятора C++), поставьте готовое колесо
(`--extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu`). **Для видеокарты нужна CUDA-сборка** (~500 МБ):

```powershell
pip install --force-reinstall --no-deps llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124 --only-binary=:all:
python scripts/check_env.py     # должно быть: выгрузка слоёв на GPU: True
```

CUDA-библиотеки llama.cpp берёт из установленного torch, поэтому приложение сначала загружает torch (`kiku/cuda_init.py`).
Без CUDA-сборки поставьте в `config.yaml` `llm.n_gpu_layers: 0` — всё посчитается на процессоре.

```powershell
# 3. Голос и окно
pip install -r requirements-voice.txt
pip install -r requirements-gui.txt

# 4. Модели (один раз, нужен интернет). Языковая модель ~18 ГБ.
python scripts/download_models.py          # --with-design нужен только для tts.engine: qwen

# 5. Только для tts.engine: qwen — придумать голос Кику (один раз; на CPU может занять несколько минут)
python scripts/design_voice.py
#   ...или положите свою запись 3–10 с в voices/kiku_ref.wav и её дословный текст в voices/kiku_ref.txt
```

Для голоса по умолчанию (Silero) шаг 5 не нужен: `download_models.py` сам скачает `models/silero/v5_ru.pt` (~145 МБ).

## Запуск — рекомендую по ступеням

```powershell
python scripts/check_env.py                    # -1. что видят torch/CUDA, llama.cpp, микрофон
python -m unittest discover -s tests -v        # 0. ядро без моделей: должно быть OK

python -m kiku chat --dry-run                  # 1. LLM + инструменты, ничего реально не выполняется
python -m kiku chat                            # 2. то же, но по-настоящему
python -m kiku chat --tts                      # 3. + голос Кику
python -m kiku voice                           # 4. полный голосовой режим в консоли
python -m kiku gui                             # 5. окно с Кику (то, чем вы будете пользоваться)
```

Если что-то работает медленно — запускайте с `-v` и смотрите замеры: `LLM: N ток. за X с`, `TTS: … RTF`,
а в голосовом режиме после каждой команды печатается `[время] распознавание · агент · дозвучка`. По ним видно, что именно тормозит.
Если что-то не стартует — добавьте `-v`: увидите сырые ответы модели и замеры скорости
(`LLM: … ток/с`, `TTS: … RTF`; RTF меньше 1.0 — озвучка быстрее реального времени).
Первая ступень проверяет самое важное: понимает ли выбранная модель системный промпт и формат JSON.

## Настройка (`config.yaml`)

* `router.enabled` — быстрые команды без LLM. `windows.aliases` — разговорные названия окон («вс код», «хром»).
* `wake.conversation_window_sec` — сколько секунд после ответа Кику слушает без имени (25 по умолчанию); 0 — имя нужно всегда.
* `tts.engine` — `silero` (быстрый, по умолчанию) или `qwen` (клонирование голоса, медленнее). `tts.silero.speaker/pitch/rate` — голос, тон, темп. `tts.pronounce` — как читать латинские названия.
* `tts.max_spoken_chars` — 0: озвучивать весь ответ (по умолчанию); `tts.chunk_chars`, `tts.prewarm`, `tts.cache` — размер кусков, подготовка и кэш типовых фраз.
* `gui.start_maximized` — открывать окно на весь экран; `gui.width/height` — размер, если нет.
* `wake.words` — варианты имени, под которые подстраивается распознавание; `wake.fuzzy_ratio` — строгость сравнения.
* `security.allowed_roots` — папки, внутри которых Кику вообще может что-то делать.
* `apps` — белый список приложений. Для CS2 уже есть `steam://rungameid/730`. Добавляйте свои.
* `llm.repo_id / file_pattern` — модель. Закомментированы варианты полегче (Qwen3-4B) и новее (Qwen3.6-35B-A3B).
* `llm.n_gpu_layers` — слоёв LLM на видеокарте (99 = все, 0 = всё на CPU). `llm.n_cpu_moe` — сколько первых слоёв держать эксперты MoE в ОЗУ
  (48 = все; меньше число = быстрее, но больше видеопамяти: каждый слой ≈ 0.4 ГБ). `llm.kv_cache_q8` — KV-кэш в 8 бит. Подобрать: `python scripts/bench_llm.py --gpu-layers 99 --cpu-moe 48 --kv-q8`.
* `scenes` — режимы («я играть»): `aliases` (фразы), `say` (что сказать), `steps` (инструменты по порядку). `proactive` — утренняя сводка и напоминания о перерывах.
* `internet.enabled` — разрешить погоду и курсы (по умолчанию `false`, Кику полностью офлайн); `internet.city` — город по умолчанию.
* `asr.device`, `tts.device` — `cuda`/`cpu`. Если не хватает VRAM, переведите ASR на `cpu`.
* `tts.qwen.mode` — `clone` (голос из `voices/`) или `custom` (готовый тембр без подготовки).
* `security.offline: true` — после скачивания моделей сетевые обращения Hugging Face запрещены.

## Как добавить инструмент

Инструмент — обычная функция. Сигнатура сама попадёт в системный промпт, типы аргументов приводятся автоматически.
Добавьте в `register_system_tools` (или создайте новый модуль и зарегистрируйте в `app.py`):

```python
@reg.tool("lock_screen", "Заблокировать компьютер.")
def lock_screen() -> str:
    if ctx.dry_run:
        return "[dry-run] заблокировала бы экран"
    if not ctx.confirm("Заблокировать компьютер?"):      # подтверждение хозяина
        raise ToolError("хозяин не подтвердил")
    import ctypes; ctypes.windll.user32.LockWorkStation()
    return "экран заблокирован"
```

Правила: возвращайте короткие данные; ожидаемые ошибки — через `ToolError`; всё опасное — через `ctx.confirm`;
не используйте `from __future__ import annotations` в файлах с инструментами.

## Безопасность

Подробно — `docs/SECURITY.md`. Коротко: Кику не имеет инструмента «выполнить команду», не читает содержимое
файлов, работает только в разрешённых папках, запускает только приложения из белого списка, не создаёт
исполняемые файлы и скрипты, перезапись/удаление памяти требует голосового «да», каждое действие пишется
в `data/audit.jsonl`.

## Docker — почему пока не включён

Контейнер Linux не может открывать папки и запускать приложения **на вашем Windows**, а проброс микрофона и
звука в контейнер на Windows — отдельная боль. Поэтому v0.1 ставится нативно. Для «запустил контейнер — работает»
разумная схема такая: в контейнере живут «мозги» (LLM, память, агент, HTTP API), а на Windows — маленький
«исполнитель» с теми же проверками безопасности, который выполняет разрешённые инструменты. Код уже разделён так,
чтобы это можно было сделать следующим шагом (инструменты изолированы за `ToolRegistry`).

## Дорожная карта

1. Вы запускаете ступени 0–4 и присылаете вывод ошибок; я чиню.
2. Перебивание голосом (barge-in) и настоящий wake word (openWakeWord, свой «Кику»): нужно эхоподавление и обучение модели слова.
3. Аватар Live2D / VRM, режим «питомец на рабочем столе».
4. Разделение «мозги/исполнитель» + Docker.
5. Семантический поиск по содержимому (эмбеддинги, PDF/Word) вместо поиска по словам; сейчас индексируются только текстовые файлы.
6. Суб-агент экрана (локальная VLM) и управление интерфейсом: «клавиатура прежде всего», проверка результата.

## Известные риски

* Если TTS пишет, что CUDA недоступна, значит, в окружении стоит torch без CUDA: переустановите по шагу 1 установки.
* Возможны несовпадения версий API (`qwen-tts`, `llama-cpp-python`, `faster-whisper`) — зафиксируйте версии, когда всё заработает.
* Пока Кику думает и говорит, микрофон закрыт: имя, сказанное в это время, она не услышит. Подождите, пока она договорит.
* 4 ГБ VRAM — впритык для ASR и TTS одновременно. Если будет `CUDA out of memory`: `asr.device: cpu` или модель `small`.
* `faster-whisper` на GPU под Windows может требовать библиотек CUDA 12/cuDNN 9 (`pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`).
* Silero: голоса фиксированные (клонировать свой нельзя), эмоции ограничены тоном и темпом; редкие слова иногда с неверным ударением.
  У Qwen3-TTS русский — самый слабый из языков по ошибкам произношения.
* Новые архитектуры LLM (Qwen3.5/3.6) могут быть не поддержаны вашей версией `llama-cpp-python`.
* Решение об «имени в тексте» может ложно срабатывать на похожие слова; настраивается в `wake.fuzzy_ratio`.
* Языковой модели с набором из ~40 инструментов нужно больше времени на разбор запроса (ответ LLM 5–10 с); типовые команды идут мимо неё и мгновенны.
* Иностранный текст (перевод) озвучить нельзя: Silero читает только русский. Такие результаты Кику кладёт в буфер обмена.
* Диктовка («набери текст…») нажимает Ctrl+V в активном окне: убедитесь, что курсор стоит там, где нужно.
