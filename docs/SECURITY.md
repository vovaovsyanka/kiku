# Безопасность Кику

## Модель угроз

Главная опасность для агента, управляющего ПК, — **инъекция инструкций через данные**: имя файла, текст заметки,
название задачи, содержимое документа могут содержать «приказы» для модели. Поэтому:

| Мера | Где |
|---|---|
| Нет инструмента «выполнить команду/скрипт» | `kiku/tools/` |
| Файловая система ограничена `allowed_roots`; `..`, UNC и чужие диски отклоняются | `tools/paths.py` |
| Создание/открытие `.exe .bat .ps1 .js .lnk .reg …` запрещено; открытие `.py` через ассоциации запрещено | `blocked_extensions` |
| Запуск приложений только из белого списка `apps` (сопоставление по алиасам) | `launch_app` |
| Перезапись файла и удаление из памяти — только после голосового/текстового «да» | `ctx.confirm` |
| Индекс хранит только имена файлов; содержимое читается лишь инструментом `read_text_file` (только текстовые типы, до 4000 символов) | `memory/store.py`, `system_tools.py` |
| После чтения файла в этом же запросе разрешены только «читающие» инструменты; создание файлов, запуск, закрытие окон и т.п. блокируются (защита от «приказов» в тексте файла) | `agent/core.py` |
| Результаты инструментов и факты в промпте помечены как данные, не команды | `persona.py` |
| Журнал каждого вызова инструмента с аргументами и результатом | `data/audit.jsonl` |
| Сеть Hugging Face запрещена после скачивания (`HF_HUB_OFFLINE=1`) | `env.py`, `security.offline` |
| Веб-интерфейс только на 127.0.0.1, проверка `Origin` у WebSocket, вывод через `textContent` | `ui/web.py` |
| Пробный режим: `--dry-run` | `ToolContext.dry_run` |

## Остаточные риски (честно)

* Модель, которую удалось обмануть, всё ещё может создавать мусорные файлы в разрешённых папках и запускать
  разрешённые приложения. Поэтому белый список коротким держать полезно.
* **Отравление памяти:** сохранённый факт попадает в системный промпт всех будущих реплик. Просматривайте память
  (`recall`, файл `data/kiku.db`) и удаляйте лишнее (`forget`).
* Распознавание речи может услышать команду из фильма или от соседа: сейчас нет проверки голоса говорящего.
* Прочитанный текст файла всё же попадает в контекст модели: он может исказить её ответ (например, соврать в пересказе),
  хотя менять систему в этом запросе она уже не сможет. Для будущего RAG по документам нужна такая же изоляция.
